# SigVTA Full Dataset Access Request

The full SigVTA dataset (79 writers, 7,900 signatures) is not included in this repository. It is available only for non-commercial academic research and must not be used for any commercial purpose.

To request it, copy the form below into an email, fill in every field, and send it to [Jiang_bohan@163.com](mailto:2846512082@qq.com) with the subject line `SigVTA access request`.

Approved requests receive a time-limited download link by email.

---

## Request form

```text
Name:
Affiliation (university / institute):
Position (e.g. student, postdoc, faculty):
Institutional email address:
Supervisor (required for students):

Intended use (which task, method, or study):
Expected publications:

I confirm that:
[ ] I will use the data for non-commercial academic research only.
[ ] I will not use the dataset for any commercial purpose.
[ ] I will not redistribute the dataset, in whole or in part.
[ ] I will not attempt to identify any participant or link the data
    to other sources for that purpose.
```

Incomplete forms are returned for clarification rather than processed.
